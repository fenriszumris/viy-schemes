Время в игре

Игровое время - это один счётчик gametime.gametime. Все места в коде, где он меняется, собраны ниже. Единиц времени в минутах нет: в коде это просто число от 0 до 50. Граница проверки: поиск подстроки «gametime» по всем файлам .rpy (25 строк в 7 файлах), отдельно все вызовы change_day и все присваивания my_location.name (через них идёт +1). Обращений через getattr/setattr/строковое имя к счётчику не найдено; в игре getattr/eval есть только для картинок, музыки и стрелок. Полнота скрытых динамических изменений не доказана. Сбросов счётчика в игре, кроме создания при старте (script _define.rpy:217) и отладочной кнопки, не найдено.

Других присваиваний счётчика в коде нет (поиск gametime по всем .rpy). Дорога между двумя местами по стрелке даёт всегда +1, зависимости от расстояния в коде нет. Стрелка, у которой есть только метка перехода без целевой локации, сама время не добавляет: оно добавится, если сцена по метке переносит героиню присваиванием (см. список ниже).
