Настроение000

Повторный визит на локацию после разговора day_1 (флаг «korn», day_1_less_razg:56) открывает одноразовую ветку наваждения в осмотре спальников (флаг «spal», begin:340): «Бороться с наваждением.» → Безумие −2 (begin:352) или «Поддаться потоку.» → Кровь +1 (setblood 412) — ветки взаимоисключающие. С учётом ревизита: минимум Безумия −2 (совместим с Кровью +1), максимум Крови +2 (укус руки hand:77 + поток; совместим с Безумием +5); Безумие −2 и Кровь +2 на одном пути несовместимы. В таблицу первого прохода эти эффекты не входят.

*Типичный путь: один путь из схемы, выбранный по самым вероятным выборам (суждение, не среднее). Путь: «Укусить себя за руку, вдруг все это сон?» → «Укусить еще сильнее. Для верности.» → «Бежать.» → «Пожалуйста! Не трогайте меня!». Мин и макс считаются по всем путям, пути к смертям тоже.

Как читать

«Хаб» — кусок сцены с меню выборов. Эффекты: mad — Безумие, logic — Логика, blood — Кровь, mood — Настроение (в этой сцене не меняется). «Экран стрелок» — переход на экран перемещения: дальше игра идёт по экрану, а не по коду метки. Ветка руки и корней входит в разговор с Лессом напрямую (conv_2), минуя гляделки; остальные выходы — через экран стрелок (conv_0/conv_1). Сам разговор — на странице «Разговор с Лессом».

Сейчас показана ДЕТАЛЬНАЯ схема

Полная схема: все хабы и все выборы

Плашки на хабе: минимум и максимум по всем путям внутри хаба от входа до выхода (со вложенными меню и циклами, с учётом разовых флагов и повторов причин); включая пути к смертям, как в таблицах статов ниже.

Блок-схема: хабы свёрнуты. Клик по блоку хаба раскрывает его ветки, повторный клик сворачивает. У каждого хаба свой цвет ветки.

Значки на выборах: ▲/▼ Настроение · ▲/▼ Кровь · ▲/▼ Безумие · ▲/▼ Логика. Плюсы — вверху справа карточки, минусы — внизу слева. Плашка на хабе — диапазон прямых изменений статов внутри хаба (по коду).







Детали по хабам


Сцены 0–1. Вход (hard, start3)


    

  • hard (script.rpy:846): обучение и вопрос про HARDMODE (без отката, автосохранений и истории). На 7-й отказ включается принудительно. Статов нет.
    • 

  • start3 (begin:6): меню разработчика. razr = 1 стоит жёстко, поэтому меню видит каждый игрок. «Игра» → tash_game (мини-игра, вне схемы), «Обучение» → назад в начало, «Без разработчика» / «Все, кроме Лесса.» → стартовое меню, «С.» → меню локаций (экран стрелок).
    • 



Хаб 1. Стартовое меню (start_menu, begin:152)


    

  • Лупа «осмотреться» (start_osm1, begin:190, add_logic 193): Логика +1 один раз (флаг v1.d1). Причина «Осмотр окружения» — та же строка используется у лупы амулета в разговоре с Лессом: там повторно не начислится.
    • 

  • «Пойти дальше.» → script_2_less_conv_1 → экран стрелок.
    • 



Хаб 2. Сон (c1_sleep → head_ache, begin:245, mem:41-197)


    

  • Вход: c1_sleep (Безумие +1 на входе, учтён на карточке выбора в хабе 1). Проигрывается воспоминание о матери (mather_memory, без статов).
    • 

  • son → sud_memory → head_ache (setblood: Кровь +1). «Идти до конца!» → BAD END «Вспомнить все...», перезапуск игры.
    • 

  • Остальные выходы → script_2_less_conv_0 → экран стрелок.
    • 



Хаб 3. Рука и корни (hand:1-295)


    

  • Вход: c1_hand (Безумие +1 на входе, учтён на карточке выбора в хабе 1). hand_next: setblood Кровь +1.
    • 

  • Лупа «осмотреть ситуацию» (zeml_osm, hand:150): Логика +1 один раз (флаг vd1.d1).
    • 

  • «Пожалуйста! Не трогайте меня!» (zeml_ran, выбор hand:209, флаг 219) ставит poter_v_less = True: этот флаг решает, будет ли героиня искать Лесса в конце разговора (ветка «потеряшки»).
    • 

  • «Ничего не делать» → BAD END «Подкормка...». Тот же ключ deaths_list["less_eat"], что у смерти от корней в конце разговора, — две разные смерти пишутся в одну запись.
    • 

  • Выходы ветки (shh, zeml_ran) → script_2_less_conv_2: разговор начинается сразу, гляделки (start_cycle) пропускаются.
    • 




Кликабельные осмотры экрана стрелок (стартовая локация)


    

  • Все входы — clicked Jump в script_npc_items.rpy; выход обратно на экран (call_screen_strel).
    • 

  • Куча корней/спальников (script_1_less_spal, begin:322-429, вход npc_items:494). Если "korn" в vrem_memory["viy_quest"] — наваждение с меню: «Бороться с наваждением.» → Безумие −2 (352); «Поддаться потоку.» → видение (эльфы, Риал, пленница) → Кровь +1 (setblood 412). Без «korn» — короткий осмотр (флаг spal0, 329). Флаг «korn» появляется только в разговоре day_1 (day_1_less_razg:56), то есть ветка наваждения достижима при повторном визите на локацию, не при первом проходе.
    • 

  • Табличка «Территория Лесса» (script_1_less_tabl, begin:286-321, вход npc_items:614). «Взять с собой.» — корешок хлещет (blood_effect, Кровь не меняется); «Оставить на месте» — выход. Статов нет.
    • 

  • Кровавый отпечаток на дереве (script_1_hand_blood, begin:528-552, вход npc_items:557): реплики по уровням Логики/Безумия. Статов нет.
    • 

  • Кремень (kremen_action_osm, begin:553-590, вход npc_items:585): меняет inv_list["kremen"]._text (гравировка «РДС», связка с факелом при facel._active). Статов нет.
    • 

  • Пять луп-направлений (begin:430-527: less_start_left/right_osm_label, less_per_left/right/up_osm_label): метки собираются динамически namee+napr+"_osm_label" (script.rpy:439-443), раскрывают подписи стрелок «???» → имя, доп. реплики по уровням Логики/Безумия. Статов нет.
    • 

  • prop_memory / prop_memory2 (script_memory:230, 245): вызывающий не найден в проверенном наборе файлов. Не мёртвый код: вызов может быть в файлах вне набора — не подтверждено.
    •
