Настроение: что его меняет

Автоматически собрано из всех доступных файлов игры: каждая строка кода вида «персонаж.mood += N». Пункт меню указан, только если строка вложена в него по структуре кода (отступы); если строка достигается через переход из другого места, пункт не указан. Если внутри пункта есть свои условия, изменение происходит только в своей ветке (одна строка с одним пунктом может встретиться дважды с разными числами). Переходы между метками (jump/call) не прослежены, привязка проверена только по вложенности. Квесты - ниже отдельным блоком.
