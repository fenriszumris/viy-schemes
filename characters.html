Настроение: что его меняет

Автоматически собрано из всех доступных файлов игры: каждая строка кода вида «персонаж.mood += N». Пункт меню указан, только если строка вложена в него по структуре кода (отступы); если строка достигается через переход из другого места, пункт не указан. Если внутри пункта есть свои условия, изменение происходит только в своей ветке (одна строка с одним пунктом может встретиться дважды с разными числами). Переходы между метками (jump/call) не прослежены, привязка проверена только по вложенности. Строки со значком ⛔ недостижимо находятся в коде, до которого доказанно нельзя дойти (мертвая цепочка Адро; меню после безусловного renpy.full_restart()): оставлены как реестр кода, живым эффектом не являются. Остальные строки по вложенности живые, но их фактическая достижимость через переходы отдельно не проверялась. Квесты - ниже отдельным блоком.
