# Схемы игры «Вий»

Статический сайт со схемами сюжетных веток игры «Вий» (визуальная новелла, Ren'Py).
Собран строго по исходному коду из репозитория `Kraka42/viy_demo` (только чтение).

## Страницы
- `index.html` — главная, легенда, навигация
- `start.html` — сцена «Старт»: от начала игры до разговора с Лессом (диаграмма Mermaid)
- `less.html` — разговор с Лессом: карта хабов и выборов
- `stats.html` — мин/макс статов по сценам и найденные в коде ошибки

## Как редактировать
1. Текст страниц — обычный HTML в файлах выше.
2. Диаграммы — блоки `<pre class="mermaid">...</pre>`: это текст Mermaid (https://mermaid.js.org),
   правится прямо в файле; можно вставить текст в https://mermaid.live для визуальной правки.
3. После коммита в ветку `main` сайт обновляется автоматически (GitHub Pages).
