Что важно

  • Единственная проверка oh.mood, меняющая ход сцены: «Я все узнала что хотела» при oh.mood < 0 без амулета (610): Адриан гасит свет и ведёт в noadr. Остальные проверки (434, 537, 663, 679) меняют только текст.
  • «Эй, не приказывай мне!» (141) доступен при безумии ≥ 3; «Можете объяснить, где я?» (178) при логике ≥ 2.
  • Ветка Вия (viy_razg и ниже) открывается пунктом «Вий.» при viy.zn_name == True (имя узнано в сцене Таши, nazad:810, 1152) или если имя героини уже «Вий».
  • Не смоделировано: ветка dev.near (18-67), razr (13-17), повторные визиты, amulet() = 1 (активен, но не «keep»), ввод имени в ne_viy5 (986).

Ошибки и особенности кода

  • «Взять очень осторожно.» (792) → jump script_3_tgavan_adr_after_door (837): метки нет в доступных файлах игры, похоже на падение. Стоит проверить, не лежит ли она в другом файле.
  • Флаги без присваивания: od4.d1 (741, 761, 776), od3.d4 (580) и pd_tgavan (909, 929) только читаются, нигде не присваиваются в доступных файлах. Ветка «Она снова здесь» (776-778) недостижима.
  • $ script_3_tgavan_begin_adr_door_razg (992) — имя метки как выражение, без jump: ничего не делает.
  • $ logic +=1 (181) — голая переменная, не sanity.add_logic: логика не меняется.
  • Метки tg_dv_amul (1049, вход «с амулетом») и tgavan_exit (1102) без входящих переходов в доступных файлах.
  • «Наплевать на предупреждение» (838) можно повторять: без амулета ещё один фиал, с амулетом два; безумие +1 за каждый заход.
